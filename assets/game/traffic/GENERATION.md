# Traffic variants

Generated with the built-in image generation tool, using `traffic_car_yellow.png` as the camera, lighting and render-style reference. The original yellow asset is retained. Each new PNG is a separate vehicle with its generated transparency preserved; no runtime tint is applied to windows, tires or tail lights.

The new files are `traffic_hatchback_blue.png`, `traffic_suv_white.png`, and `traffic_sedan_green.png`. Each appearance is assigned once per traffic block, independently of gameplay randomness. Sprite registration matches the existing traffic width and wheel baseline using measured alpha bounds, without stretching the car or changing its collision box.
